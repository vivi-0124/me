# MD Note

Raycast Notes のように、コマンドを打つとエディタが開く Markdown ノート。書いた内容は、設定したフォルダに `.md` ファイルとして自動で保存する。

## コマンド

| コマンド                | 動作                                                                                   |
| ----------------------- | -------------------------------------------------------------------------------------- |
| `Open Markdown Editor`  | 最後に開いていたノートをエディタで開く（無ければ新しいノート）                         |
| `Create Markdown Note`  | 新しいノートをエディタで開く                                                           |
| `Search Markdown Notes` | 保存先フォルダのノートを、右側のプレビュー付きで一覧する。ファイル名と本文で絞り込める |

`Open Markdown Editor` にホットキー（例: `⌥ + N`）を割り当てると、Raycast Notes と同じ感覚で呼び出せる。

## エディタ

- 本文欄は Markdown の装飾付きで表示される（見出し・太字・コードなどが入力中にそのまま色付く）。`⌘B` / `⌘I` などの書式ショートカットも使える
- 打つのを止めて 0.4 秒たつと自動で保存する。何も書いていない新しいノートはファイルを作らない
- ファイル名欄を変えて、フォーカスを外すとファイル名が変わる。同じ名前のファイルが既にあるときは変えない
- 新しいノートの名前は日時（例: `2026-11-02 14.05.09`）

| キー    | 動作                                 |
| ------- | ------------------------------------ |
| `⌘ ↵`   | プレビュー（全体を描画して表示する） |
| `⌘ E`   | プレビューからエディタに戻る         |
| `⌘ S`   | 今すぐ保存                           |
| `⌘ N`   | 新しいノート                         |
| `⌘ O`   | 別のノートを開く（一覧から選ぶ）     |
| `⌘ ⇧ C` | Markdown をコピー                    |
| `⌘ ⇧ F` | Finder で表示                        |
| `⌃ X`   | ノートを削除                         |

## 設定

初回起動時に **保存先フォルダ** を選ぶ。あとから Raycast の設定（Extensions → MD Note）で変えられる。

- フォルダ直下の `.md` だけを扱う（サブフォルダは見ない）
- 他のエディタ（VS Code・Obsidian など）で同じフォルダを開いて編集してもよい

## できないこと

Raycast の拡張機能は決まった UI 部品（Form・Detail・List など）しか使えず、書く欄と描画結果を同じ画面に左右で並べることはできない。そのため次のようにしている。

- 書いている最中は、本文欄の Markdown 装飾表示で見た目を確かめる
- 全体の描画結果は `⌘ ↵` のプレビューで見る
- 一覧（`Search Markdown Notes`）では左に一覧、右に描画結果が出る

## 開発

```bash
npm install
npm run dev
npm run lint
npm run build
```

| パス                          | 役割                                                        |
| ----------------------------- | ----------------------------------------------------------- |
| `src/components/Editor.tsx`   | エディタ（自動保存・名前の変更・各アクション）              |
| `src/components/Preview.tsx`  | プレビュー（Detail で Markdown を描画）                     |
| `src/components/NoteList.tsx` | ノート一覧（プレビュー付き・本文検索）                      |
| `src/lib/notes.ts`            | 保存先フォルダの .md の読み書きと、最後に開いたノートの記録 |
| `src/open-editor.tsx` ほか    | 各コマンドの入口                                            |
