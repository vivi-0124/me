# Kana Retype

英数モードのまま打ってしまったローマ字を、消さずに かなモードで打ち直す拡張機能。

```
konnnitiha を選択 → ショートカット → こんにちは（未確定。スペースで漢字に変換できる）
```

## 使い方

1. 英数モードで打った文字列を選択する
2. `Retype Selection as Kana` に割り当てたショートカットを押す
3. 選択範囲が、かなモードで同じキーを打った結果に置き換わる（未確定のまま）

## 動作

- `getSelectedText` で選択中の文字列を取る
- System Events で「かな」キー（key code 104）を送り、かなモードに切り替える
- 選択中の文字列と同じキーを `keystroke` で送る。最初のキーで選択範囲が上書きされる
- ターミナル系のアプリでは、先に BackSpace を文字数ぶん送って元の文字を消す（下の「ターミナルでの動き」）
- 空白は Space キー（かなモードでは変換）、改行は Return キー（確定）、タブは Tab キーとして送る

| 状況                                       | 動作                                         |
| ------------------------------------------ | -------------------------------------------- |
| 選択が無い                                 | HUD「文字列を選択してください」を出して終了  |
| 英数字と記号以外（かな・漢字・全角）を含む | HUD で該当文字を知らせて終了。キーは送らない |
| System Events を操作できない               | HUD で権限の確認を促す                       |

## ターミナルでの動き

ターミナルの選択は画面の表示を選んでいるだけで、入力欄の編集範囲ではない。そのため打っても選択範囲は置き換わらず、`kakaka` → `kakakaかかか` のように元の文字が残る。

これを避けるため、一番手前のアプリが次のどれかのときは、**カーソルの直前から選択した文字数ぶんを BackSpace で消してから**打ち直す。

- Terminal / iTerm2 / Ghostty / WezTerm / Alacritty / kitty / Warp / Hyper / Tabby / Orca

注意点:

- 消すのは「カーソルの直前の N 文字」。打った直後（カーソルが末尾にある状態）で使う前提
- VS Code の統合ターミナルのように、エディタとターミナルが同じアプリにあるものは見分けられない。ターミナル側でよく使うなら、設定の **Terminal Apps** に bundle ID（例: `com.microsoft.VSCode`）を追加する。その場合、エディタ側でもカーソル直前を消す動きになる

## 設定 (Preferences)

- **Terminal Apps**: BackSpace で消してから打ち直すアプリの bundle ID をカンマ区切りで追加する。bundle ID は `osascript -e 'id of app "アプリ名"'` で調べられる

## 前提

- 入力ソースは macOS 標準の日本語入力（ローマ字入力）
- JIS キーボード（「かな」キーがある）
- Raycast に次の 2 つを許可する
  - システム設定 → プライバシーとセキュリティ → **アクセシビリティ** → Raycast
  - システム設定 → プライバシーとセキュリティ → **オートメーション** → Raycast → System Events

## 対象外

- 選択していない文字列を自動で選択すること
- 漢字への変換・確定の自動化

## 開発

```bash
npm install
npm run dev
npm run lint
npm run build
```

| パス                    | 役割                                              |
| ----------------------- | ------------------------------------------------- |
| `src/retype-as-kana.ts` | コマンド本体（選択の取得・チェック・キー送信）    |
| `src/lib/terminal.ts`   | ターミナル系アプリの判定                          |
| `src/lib/keys.ts`       | 打てない文字の検出と、送るキーの AppleScript 生成 |
