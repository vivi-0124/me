# Chrome Tab Switcher Changelog

## [公開版にそろえた] - 2026-11-07

- 名前を `Chrome Tab Search` から `Chrome Tab Switcher` に変えた（Store では新しい拡張機能になる）
- 説明文、README、スクリーンショット、デモ GIF を公開版と同じにした
- ウィンドウの読み取りエラーや検索結果 0 件の表示など、公開版の最新の修正を反映した

## [公開版の修正を反映] - 2026-11-07

- 最小化されたウィンドウのタブを選んだときに、ウィンドウを復元するようにした
- 読み込みに失敗したときに、エラーと Retry を画面に表示するようにした
- 読み取り中にタブが変わっても、タイトルと ID がずれないようにした
- 読み込めなかったウィンドウがあるときに、警告を出して Retry できるようにした
- 画面の文言を英語にした
- アイコンを新しくした

## [Initial Version] - 2026-11-06

- Chrome のタブをウィンドウ横断で検索して切り替える `Search Chrome Tabs` を追加した
